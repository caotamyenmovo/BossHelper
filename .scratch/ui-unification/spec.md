# 统一求职工具正式界面
Status: resolved

## 已确认方向

- 克制、紧凑、清晰；浅灰白、低饱和青绿、小圆角、细分隔线、统一图标，支持深色。
- 优先简历、建议和面试。扩展最终默认简历页，求职功能成为一级导航，配置归入设置。
- 简历建议采用来源与建议并列，原简历按需查看；顶部保留简历及目标岗位上下文。
- Boss 投递允许重排，账号/预设、开始或暂停、进度与失败数量常驻；岗位为主体，筛选、日志、统计按需展开，详情及 AI 对话在侧栏。
- 用户最新指示：跳过交互样稿，直接修改正式布局。接入现有功能，复用 AI 配置、导入、存储、草稿恢复和请求隔离。
- 展示空白、加载、失败、窄窗口和深色状态，仅 C 盘工作区。

## 实现范围

独立扩展页面使用 options/App.vue 的一级导航；CareerWorkbench 保持挂载，设置重载不销毁简历草稿。建议页并列展示经验来源和生成结果，面试将当前问题和回答放在前面，历史问答可展开。

Boss 正式界面使用 DeliveryControls 常驻控制栏；统计、筛选、日志为次级页签，失败数量直达失败岗位。卡片取消堆叠和旋转，保留表格模式、上下文操作和 AI 侧栏。原生筛选只在对应页签显示，并在显示后重新测量位置。
